# AXGATE 로그 뷰어

AXGATE 방화벽이 `.adb`(SQLite) 형식으로 백업하는 로그를, SQLite에 익숙하지 않은 일반 사용자도 macOS/Windows에서 동일한 화면으로 조회·검색·필터할 수 있게 해주는 데스크탑(웹) 뷰어입니다.

> **상태**: v0.1.2. 설치 파일은 `release/` (`RELEASE_NOTES.md` 참고). ARM Windows 포터블은 zip만 사용.

## 왜 필요한가

AXGATE 장비는 로그를 `audit`/`ipsec`/`session`/`ssl`/`system`/`uauth` 6종의 `.adb` 파일(SQLite 3 데이터베이스)로 백업합니다. 컬럼 상당수가 사람이 읽기 어려운 정수 코드·엔디안이 섞인 IP 정수 등으로 저장돼 있어, SQLite 브라우저 같은 전문 도구 없이는 일반 사용자가 내용을 확인하기 어렵습니다. 이 프로젝트는 그 `.adb` 백업(및 장비 웹 UI가 내보내는 `.csv`)을 그대로 불러와 사람이 읽는 형태로 보여주는 것을 목표로 합니다.

## 주요 기능

- **파일 가져오기**: `.adb` / `.csv`를 폴더 열기·파일 열기·드래그 앤 드롭으로 가져오기. 가져오기 미리보기에서 파일별 형식·추정 로그 종류·신뢰도를 보여주고, 자동 판별이 틀렸으면 직접 재지정 가능.
- **CSV 자동 판별**: 헤더의 고유 컬럼 조합(anchor column)으로 6종 로그 중 어떤 것인지 자동 인식. 인코딩(UTF-16LE/UTF-8)·구분자(탭/콤마)도 자동 감지. 판별이 애매하면 원본 컬럼을 그대로 보여주는 제네릭 그리드로 폴백.
- **로그 보기**: 사이드바에서 세션 / 감사 / 인증 / 시스템 / IPsec / SSL-VPN 6종 전환. 로그 종류별 기본 컬럼 프리셋 + 행 클릭 시 상세 패널(해석값 / 원시 JSON 토글), 페이지네이션, IP 엔디안 디코딩, 코드값→라벨 매핑(모르는 값은 원본 그대로 노출).
- **검색·필터**: 로그 종류별 컬럼 필터(기간·IP·포트·프로토콜·동작 등, 옵션은 실제 데이터 기준으로 동적 구성) + 6종 전체를 대상으로 하는 통합 키워드 검색(하이라이트, 종류별 그룹 결과).
- **부가 UI**: 시간대별 로그량 막대그래프, 컬럼/필터 용어 설명 툴팁, 하단 상태줄, 라이트/다크/OS 테마, CSV 내보내기(UTF-8 BOM / UTF-16LE).
- **원본 보호**: `.adb`는 메모리에서만 읽어(sql.js) 원본 폴더에 `-wal`/`-shm` 등 부산물을 만들지 않으며, 앱은 외부로 데이터를 전송하지 않는 완전 오프라인 동작을 원칙으로 함.

## 기술 스택

- UI: React 19 + TypeScript + Vite, 한글 폰트 [Noto Sans KR](https://fonts.google.com/noto/specimen/Noto+Sans+KR)
- 데스크탑 셸: Electron 37 (`electron-builder` NSIS/zip/dmg)
- 데이터베이스 접근: [sql.js](https://github.com/sql-js/sql.js) (WASM 기반 SQLite) — 원본 `.adb` 파일을 읽기 전용으로만 로드
- 테스트: Vitest

## 시작하기

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173/` 을 엽니다. 개발 서버에서 "샘플 불러오기"로 로컬 샘플 로그(`adb_ex/`, 저장소에는 포함돼 있지 않음 — 아래 [샘플 데이터](#샘플-데이터) 참고)를 바로 열어볼 수 있습니다.

그 외 자주 쓰는 스크립트:

| 명령 | 설명 |
|---|---|
| `npm run dev:electron` | Electron 창으로 실행 (설치 패키지는 아님) |
| `npm run build` | 웹 프론트 프로덕션 번들 생성 (`dist/`) |
| `npm run pack` | 빌드 후 `electron-builder --dir`로 언패키지 앱 생성 |
| `npm test` | 단위/통합 테스트 실행 |
| `npm run typecheck` | TypeScript 타입 검사 |

## 프로젝트 구조

```
src/
  components/   화면 구성 요소 (필터 바, 검색 결과, 타임라인, 용어 툴팁 등)
  lib/          핵심 로직 (SQLite/CSV 파싱, 로그 종류 자동 판별, 필터·검색, 코드값 매핑, 워크스페이스 상태)
electron/       Electron 메인/프리로드 스크립트
public/         sql.js WASM 바이너리 등 정적 자산
adb_ex/         로컬 테스트용 샘플 .adb/.csv (git에는 포함되지 않음)
```

## 샘플 데이터

`adb_ex/` 폴더는 실제 방화벽 백업 형식을 검증하기 위한 로컬 샘플이며, 로그 데이터 자체가 민감할 수 있어 `.gitignore`로 저장소에서 제외되어 있습니다. 직접 테스트하려면 보유한 AXGATE `.adb` 백업 파일이나 장비 웹 UI에서 내보낸 `.csv`를 `adb_ex/`에 두고 실행하면 됩니다.

## 알려진 제한

- Windows ARM 포터블은 NSIS exe가 아니라 zip 안의 `AXGATE-Log-Viewer.exe`를 사용한다.
- 코드값 매핑표(`act` 전체 코드, `oper`, IPsec CSV 헤더 등)는 확보한 샘플이 제한적이라 미완성 — 알려지지 않은 값은 원본 그대로 표시.
- 통합 검색은 해석된(사람이 읽는) 값 기준이며, 원시 코드 검색은 아직 지원하지 않음.
- 컬럼 필터 연산자는 포함/일치 수준 (이상·이하 등 세분화는 예정에 없음).
- 웹 실행 환경에서는 OS 경로를 안정적으로 다시 열 수 없어 "최근 워크스페이스" 기능이 아직 없음.
